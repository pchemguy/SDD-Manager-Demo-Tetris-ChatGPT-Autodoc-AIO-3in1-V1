# Milestone 1.2 — Complete classic loop

## Outcome and review

Ready for closure after T-006 publication/issue closure. The shared browser app automatically falls, locks, clears lines, advances score/levels, ends on top-out and restarts. Pause/repeat/focus policy remains T-007 and release packaging remains T-008–T-010; this milestone is not a phase release.

Reviewed gravity/lock/clear/scoring transitions in core, the real session controller, active-time frame driver, live metric/status view and their integration. Clock/random I/O stays outside core. Grounded classic pieces lock only on failed downward attempts; terminal above-board locks do not overwrite cells. Compaction keeps surviving rows and independent top rows; line awards use the previous level. Soft input alone earns drop points. Score saturation preserves safe integers. Session completion is an over-state transition rather than every render/input event, so restart and repeated over-state commands cannot duplicate a completion. Frame clock resets on lifecycle status changes using the current monotonic timestamp and does not reset on ordinary movement. No unresolved in-scope code/contract finding.
