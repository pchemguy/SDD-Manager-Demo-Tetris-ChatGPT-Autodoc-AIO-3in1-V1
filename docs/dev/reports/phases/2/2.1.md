## Code review

A separate read-only reviewer assessed main/protocol/renderer preferences, navigation and permission denial, isolated preload, lifecycle cleanup, runtime assembly and tests. No Critical, Important or Minor code finding; final extraction/config/license additions were rechecked. The reviewer independently matched final candidate bytes/hash, Vite notices and version; runtime execution was not part of that review.

The asset handler preloads a fixed immutable map and never resolves request-selected filesystem paths. It rejects foreign origins, credentials/ports, encoded/traversal paths, links, private files and unsupported methods; responses carry MIME, CSP and nosniff. The window disables renderer Node integration and enables sandbox/context isolation. No general IPC or filesystem API is exposed. Blur/hide/minimize send a narrow suspension notification into the shared DOM pause/key-clear handlers; focus/show/restore never auto-resume. Destroyed/disposed targets receive no messages. Closing destroys the session.

Packaging pins Electron 43.8.3, validates the official runtime digest and x64 PE identity, rejects unsafe/duplicate/link archive entries and app collisions, removes the default Electron app, installs the shared UI/host, and writes deterministic candidate bytes atomically. Project, Electron, Chromium and Vite notices are included. No external Node, server or application backend is included in the runtime design.
