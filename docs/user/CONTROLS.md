# Classic controls

Click Start to begin, or Restart to abandon the current board and start a fresh game. Click the board to focus keyboard input. The game is designed for a desktop keyboard.

| Control | Action |
| --- | --- |
| Left / Right | Move one column; hold to repeat after the initial delay |
| Down | Soft drop; hold to repeat |
| Up or X | Rotate clockwise once per press |
| Z | Rotate counterclockwise once per press |
| P or Escape | Pause/resume while the board has focus |
| Pause / Resume button | Explicit pause/resume |
| Start / Restart button | Begin a fresh board |

Full rows disappear and award points. Clearing more rows at once earns a larger award, and higher levels fall faster. Soft drop earns one point per descended row. A blocked downward attempt locks the classic piece; a blocked spawn or a lock above the board ends the game. Restarting an unfinished game abandons that board.

Losing application focus or hiding the page pauses play. Return to the game and explicitly resume; suspended time does not advance the board. Held keys are cleared on suspension/focus changes. Keyboard actions do not operate while controls elsewhere have focus.
